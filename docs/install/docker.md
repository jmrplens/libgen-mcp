# Run with Docker

**How-to guide** — for anyone who would rather run the server in a container.

This page will cover the image published to GitHub Container Registry and Docker
Hub: running it over stdio for a client or over HTTP as a service, the transport
it picks when given no arguments, verifying its signature and provenance,
upgrading, pinning a digest and removing it. Until then, the steps are in the
[Docker section of the installation overview](overview.md#docker).
