# Install with winget

**How-to guide** — for anyone on Windows who manages software with winget.

The Windows Package Manager manifest is pending review in
[microsoft/winget-pkgs#437507](https://github.com/microsoft/winget-pkgs/pull/437507),
so `winget install` does not find the server yet. This page will cover installing,
upgrading and removing it with winget once the manifest is accepted. Until then,
the [installation overview](overview.md) lists the channels that work on Windows
today.
