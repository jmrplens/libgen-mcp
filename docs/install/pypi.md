# Install with PyPI

**How-to guide** — for anyone who would rather get the server from PyPI.

This page will cover the `libgen-mcp` wheels: running the server with `uvx` or
installing it with `pipx` or `pip`, which wheel your platform receives, verifying
what was installed, upgrading, pinning and removing it. Until then, the steps are
in the [PyPI section of the installation overview](overview.md#pypi).
