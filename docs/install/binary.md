# Release binaries and go install

**How-to guide** — for anyone who wants the executable itself, or to build it.

This page will cover the static binaries attached to every GitHub release: which
file fits which platform, verifying it against the signed `checksums.txt` and its
build provenance, putting it on your `PATH`, upgrading and removing it — and
building from source with `go install` instead. Until then, the steps are in the
[release binary](overview.md#release-binary) and [`go install`](overview.md#go-install)
sections of the installation overview.
