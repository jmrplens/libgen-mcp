# Versions and upgrades

**How-to guide** — for anyone keeping an installation current, or holding it still.

This page will explain how releases are versioned and what a major version
changes, and, per install channel, how to upgrade, pin a version and roll back.
The notes for each release are on the
[releases page](https://github.com/jmrplens/libgen-mcp/releases), which this page
links rather than copies.
