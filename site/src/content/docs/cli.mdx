This page will list every flag the `libgen-mcp` binary accepts, with its default, the environment variable that sets the same thing where there is one, the transport it applies to, and what happens when it is given a value it cannot honour. Settings that exist only as environment variables are in [Configuration](/libgen-mcp/configuration/).
