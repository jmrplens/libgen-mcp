## Which libgen-mcp is this?

Several unrelated projects share the name. This one is `jmrplens/libgen-mcp`,
registered as `io.github.jmrplens/libgen-mcp`:

|                  | This project                                                    |
| ---------------- | --------------------------------------------------------------- |
| Repository       | [`jmrplens/libgen-mcp`](https://github.com/jmrplens/libgen-mcp) |
| Language         | Go — a single static binary, no runtime to install              |
| Tools            | Four: `search`, `get_details`, `download`, `read`               |
| Download sources | Twenty-one, in a fixed chain, open access tried first           |
| Registry id      | `io.github.jmrplens/libgen-mcp`                                 |

What distinguishes it: the download chain is ordered so open-access providers
are exhausted before any shadow library is consulted, the open-access sources
themselves refuse what they may not hand over — an OAPEN identifier is confirmed
rather than guessed, lending-restricted Internet Archive scans are skipped, and
permission-hosted Gutenberg records are dropped — and its tool surface is checked
against a live, graded [LLM evaluation](/libgen-mcp/eval-results/) rather than
asserted.

## Responsible use

<LegalNotice />

libgen-mcp tries the legal open-access providers before any shadow-library
fallback, and refuses material it may not redistribute. [Responsible
use](/libgen-mcp/responsible-use/) sets out what that means in practice, what the
server declines to do, and how to raise a concern.

## Frequently asked questions

### What is libgen-mcp?

libgen-mcp is an open source Model Context Protocol (MCP) server, written in Go, for federated search, citation and reading of books, papers, comics, magazines and standards across the Library Genesis catalog (the `libgen.li` mirror family) and open-access sources. It exposes four tools — `search`, `get_details`, `download`, and `read` — to any MCP-compatible client such as Claude Code, Claude Desktop, or your own agent, so you can search for a work, export its BibTeX/RIS citation, resolve download links, and read/summarize text in plain language.

### What can libgen-mcp do?

It lets an AI assistant find a book or a paper, cite it and read it. `search` queries Library Genesis and eight further providers, `get_details` returns a record's metadata with BibTeX and RIS citations, `download` saves the file by md5, DOI or ISBN through a chain of twenty-one sources, and `read` extracts, searches and outlines the PDF, EPUB or text it saved.

The extra search providers are Anna's Archive, arXiv, Crossref, OpenLibrary, Project Gutenberg, dblp, PubMed and ERIC, all keyless, merged and deduplicated with the catalog results. By default (`auto`) they are asked only when the catalog comes up empty. An article requested by DOI goes to the open-access providers first, then to the publisher's own link, and only then to Sci-Hub and SciDB. Mirrors are discovered and cached automatically, with failover, retry with cooldown and a shared rate limiter, so the server keeps working as individual mirrors go up and down.

### Do I need an account, API key, or token to use libgen-mcp?

No. libgen-mcp requires no Library Genesis account, no API key, and no token. Every option is an environment variable with a documented default, so the server runs with zero configuration. The only email-shaped setting is the optional `LIBGEN_MCP_UNPAYWALL_EMAIL` contact address sent to the Unpaywall API for DOI lookups. It is unset by default, which disables the Unpaywall source — the keyless open-access sources (OpenAlex, Europe PMC, bioRxiv/medRxiv, the RFC Editor, NIST, Schloss Dagstuhl, the ACL Anthology, Zenodo, SciELO, the FAO Knowledge Repository, Internet Archive Scholar) and the Sci-Hub/SciDB fallbacks still serve DOIs without it. Set your own address to enable Unpaywall. The one other optional credential is `LIBGEN_MCP_CORE_KEY`, a free CORE API key that enables the `core` open-access source.

### Is libgen-mcp free and open source?

Yes. libgen-mcp is free and open source under the MIT license. The full source code is on GitHub at [github.com/jmrplens/libgen-mcp](https://github.com/jmrplens/libgen-mcp), and prebuilt binaries, a Docker image, and a Claude Desktop extension are published with each release.

### Does libgen-mcp prefer legal sources?

For articles and for books asked for by ISBN, yes. An article requested by DOI is tried at thirteen open-access providers and the publisher's own link before Sci-Hub or SciDB, and a book requested by ISBN comes only from OAPEN and public-domain Internet Archive scans. A book requested by md5 is the exception: no legal source is keyed by md5, so it comes from Library Genesis, whatever its copyright.

The thirteen are Unpaywall, OpenAlex, Europe PMC, bioRxiv/medRxiv, the RFC Editor, NIST, Schloss Dagstuhl, the ACL Anthology, Zenodo, SciELO, the FAO Knowledge Repository, Internet Archive Scholar and CORE, followed by the publisher's Crossref-deposited link and OAPEN. Those legal sources also refuse what they may not redistribute: OAPEN confirms the identifier instead of accepting a free-text match, lending-restricted Internet Archive scans are skipped, and Project Gutenberg records hosted by permission rather than in the public domain are dropped, each reported as a miss rather than dressed up as a file.
