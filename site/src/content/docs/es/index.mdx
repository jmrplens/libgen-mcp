## ¿Cuál de los libgen-mcp es este?

Varios proyectos sin relación comparten el nombre. Este es
`jmrplens/libgen-mcp`, registrado como `io.github.jmrplens/libgen-mcp`:

|                     | Este proyecto                                                   |
| ------------------- | --------------------------------------------------------------- |
| Repositorio         | [`jmrplens/libgen-mcp`](https://github.com/jmrplens/libgen-mcp) |
| Lenguaje            | Go — un único binario estático, sin runtime que instalar        |
| Herramientas        | Cuatro: `search`, `get_details`, `download`, `read`             |
| Fuentes de descarga | Veintiuna, en una cadena fija, con el acceso abierto primero    |
| Id de registro      | `io.github.jmrplens/libgen-mcp`                                 |

Lo que lo distingue: la cadena de descarga está ordenada para agotar los
proveedores de acceso abierto antes de consultar ninguna biblioteca en la
sombra, y esos proveedores rechazan lo que no pueden entregar — un identificador
de OAPEN se confirma en vez de suponerse, los escaneos del Internet Archive
restringidos a préstamo se omiten y los registros de Gutenberg alojados por
permiso se descartan. Además, su superficie de herramientas se comprueba contra
una [evaluación con LLM](/libgen-mcp/es/eval-results/) real y calificada, en
lugar de darse por supuesta.

## Uso responsable

<Aside type="caution">
	Esta herramienta accede a mirrors de terceros de Library Genesis. Eres
	responsable de respetar las leyes de derechos de autor y de propiedad
	intelectual que apliquen en tu lugar de residencia. Úsala solo para contenido
	al que tengas derecho legal de acceder.
</Aside>

libgen-mcp prueba los proveedores legales de acceso abierto antes que cualquier
reserva de biblioteca en la sombra, y rechaza el material que no puede
redistribuir. [Uso responsable](/libgen-mcp/es/responsible-use/) explica qué
significa eso en la práctica, qué se niega a hacer el servidor y cómo plantear
una duda.

## Preguntas frecuentes

### ¿Qué es libgen-mcp?

libgen-mcp es un servidor Model Context Protocol (MCP) de código abierto, escrito en Go, para la búsqueda federada, la citación y la lectura de libros, artículos, cómics, revistas y normas a través del catálogo de Library Genesis (la familia de mirrors `libgen.li`) y de fuentes de acceso abierto. Expone cuatro herramientas — `search`, `get_details`, `download` y `read` — a cualquier cliente compatible con MCP como Claude Code, Claude Desktop o tu propio agente, para que puedas buscar una obra, exportar su cita en BibTeX/RIS, resolver enlaces de descarga y leer/resumir texto en lenguaje natural.

### ¿Qué puede hacer libgen-mcp?

Realiza una búsqueda federada sobre el catálogo primario (Library Genesis) y otros ocho proveedores, devuelve metadatos y hashes MD5 por resultado, obtiene los detalles completos de un registro con citas BibTeX y RIS listas para pegar, y descarga archivos a un directorio local. Los libros se descargan por MD5 desde LibGen, y por ISBN desde las fuentes de libros con licencia abierta OAPEN e Internet Archive; los artículos se obtienen por DOI pasando primero por los proveedores de acceso abierto — Unpaywall, OpenAlex, Europe PMC, bioRxiv/medRxiv, el RFC Editor, NIST, Schloss Dagstuhl, la ACL Anthology, Zenodo, SciELO, el FAO Knowledge Repository, Internet Archive Scholar y CORE, después el enlace que el propio editor depositó en Crossref y OAPEN — y solo entonces por Sci-Hub y SciDB. La herramienta `search` consulta además fuentes extra sin clave — Anna's Archive, arXiv, Crossref, OpenLibrary, Project Gutenberg, dblp, PubMed y ERIC — fusionadas y deduplicadas junto a los resultados de Library Genesis; por defecto (`auto`) lo hace automáticamente siempre que el catálogo no devuelve nada. Los mirrors se descubren automáticamente y se cachean, con failover transparente, reintentos con enfriamiento y un limitador de tasa compartido, de modo que el servidor sigue funcionando aunque algunos mirrors caigan o vuelvan.

### ¿Necesito una cuenta, clave de API o token para usar libgen-mcp?

No. libgen-mcp no requiere ninguna cuenta de Library Genesis, ninguna clave de API ni ningún token. Cada opción es una variable de entorno con un valor por defecto documentado, así que el servidor funciona sin configuración alguna. El único ajuste con forma de email es la dirección de contacto opcional `LIBGEN_MCP_UNPAYWALL_EMAIL` que se envía a la API de Unpaywall para las consultas por DOI. Está sin definir por defecto, lo que desactiva la fuente Unpaywall — las fuentes de acceso abierto sin clave (OpenAlex, Europe PMC, bioRxiv/medRxiv, el RFC Editor, NIST, Schloss Dagstuhl, la ACL Anthology, Zenodo, SciELO, el FAO Knowledge Repository, Internet Archive Scholar) y los fallbacks Sci-Hub/SciDB siguen sirviendo DOIs sin ella. Fija tu propia dirección para activar Unpaywall. La única otra credencial opcional es `LIBGEN_MCP_CORE_KEY`, una clave gratuita de CORE que habilita la fuente de acceso abierto `core`.

### ¿libgen-mcp es gratis y de código abierto?

Sí. libgen-mcp es software libre y de código abierto bajo la licencia MIT. El código fuente completo está en GitHub en [github.com/jmrplens/libgen-mcp](https://github.com/jmrplens/libgen-mcp), y con cada release se publican binarios precompilados, una imagen de Docker y una extensión para Claude Desktop.

### ¿libgen-mcp prioriza las fuentes legales?

Sí, por diseño. La cadena de descarga está ordenada para que los proveedores de acceso abierto se prueben primero: un artículo pedido por DOI pasa por Unpaywall, OpenAlex, Europe PMC, bioRxiv/medRxiv, el RFC Editor, NIST, Schloss Dagstuhl, la ACL Anthology, Zenodo, SciELO, el FAO Knowledge Repository, Internet Archive Scholar y CORE, después el enlace que el propio editor depositó en Crossref y OAPEN, antes de que Sci-Hub o SciDB se consideren siquiera, y un libro pedido por ISBN solo procede de OAPEN y de escaneos de dominio público de Internet Archive. El servidor además rechaza material que no puede redistribuir: confirma el identificador de OAPEN en lugar de aceptar una coincidencia de texto libre, se salta los escaneos de Internet Archive restringidos a préstamo, y descarta los registros de Project Gutenberg alojados con permiso en lugar de estar en dominio público. Un rechazo se informa como una ausencia, nunca se disfraza de fichero.
