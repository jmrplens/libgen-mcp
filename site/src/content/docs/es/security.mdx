Esta página describirá en qué confía el servidor y qué rechaza: qué rutas locales puede abrir `read`, a qué destinos salientes se conecta, cómo se evita que el texto de terceros se lea como instrucciones, qué comprueba un despliegue HTTP antes de responder y cómo una clave por llamada se usa una vez y nunca se guarda. Cómo informar de una vulnerabilidad está en la [política de seguridad](https://github.com/jmrplens/libgen-mcp/blob/main/SECURITY.md).
