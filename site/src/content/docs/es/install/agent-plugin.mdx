Esta página cubrirá los dos manifiestos de plugin que publica este repositorio — el de Open Plugins en `.plugin/` y el de Agent Plugins en la raíz —, qué herramientas lee cada uno, cómo instalar el servidor a través de ellos y en qué se diferencia de registrar el servidor a mano. Mientras tanto, la [instalación](/libgen-mcp/es/install/overview/) enumera todos los demás canales.
