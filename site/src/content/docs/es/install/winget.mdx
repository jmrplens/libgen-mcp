---
title: Instalar con winget
description: "El manifiesto de libgen-mcp para el Windows Package Manager, pendiente de revisión, y los canales que funcionan en Windows mientras no se acepta."
---

El manifiesto del Windows Package Manager está pendiente de revisión en [microsoft/winget-pkgs#437507](https://github.com/microsoft/winget-pkgs/pull/437507), así que `winget install` todavía no encuentra el servidor. Esta página cubrirá cómo instalarlo, actualizarlo y quitarlo con winget cuando se acepte el manifiesto. Mientras tanto, la [instalación](/libgen-mcp/es/install/overview/) enumera los canales que ya funcionan en Windows.
