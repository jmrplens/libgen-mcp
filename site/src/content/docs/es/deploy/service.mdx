---
title: Ejecutarlo como servicio
description: "Ejecutar el servidor HTTP de libgen-mcp como servicio del sistema: un fichero de unidad, un puerto TCP o un socket unix, el drenaje ordenado y la comprobación de salud."
---

Esta página cubrirá cómo ejecutar el servidor como un servicio del sistema de larga duración: un fichero de unidad completo, la escucha en un puerto TCP o en un socket unix, el fichero de entorno, cómo una señal de parada drena las llamadas en curso y la comprobación de salud que puede lanzar un supervisor. El comportamiento que controla cada ajuste se describe en [Modo servidor HTTP](/libgen-mcp/es/http-server-mode/).
