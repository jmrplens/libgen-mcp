---
title: Detrás de un proxy inverso
description: "Configuraciones completas de proxy inverso para el transporte HTTP de libgen-mcp: proxies de confianza, la URL pública, streaming sin búfer y TLS."
---

Esta página reunirá configuraciones completas de proxy inverso para el transporte HTTP: qué opciones le dicen al servidor que está detrás de un proxy y qué cabecera lleva la dirección del llamante, cómo declarar la URL pública, cómo evitar que se almacenen en búfer las respuestas en streaming y cómo terminar TLS en el proxy o en el servidor. El comportamiento en el que se apoyan esas configuraciones se describe en [Modo servidor HTTP](/libgen-mcp/es/http-server-mode/).
